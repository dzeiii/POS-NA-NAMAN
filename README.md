# Gulps & Grubs POS System

A beginner-friendly Streamlit + SQLite POS MVP with three modes and manually implemented DSA.

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this project folder.
3. Install dependencies: `pip install -r requirements.txt`
4. Start the app: `streamlit run app.py`
5. Open the local URL shown in the terminal.

SQLite data is stored in `data/gulps_grubs.db`. Keep that file when backing up your records.

## Modes
- **Cashier:** search products, build a linked-list cart, choose order priority, submit orders, and view the queue.
- **Admin:** add/edit/delete/search products, view completed sales, low-stock alerts, and update order statuses.
- **Inventory Manager:** add and delete raw-material records, record restocks, and adjust finished menu-product stock.

## DSA mapping
- **Linked List:** `modules/dsa.py` — dynamic cart insertion, removal, traversal, and total.
- **AVL Tree:** `modules/dsa.py` — self-balancing product-name index used for cashier search.
- **Min-Heap:** `modules/dsa.py` — pending order queue; rank 1 Urgent, 2 High, 3 Normal. Earlier timestamp breaks ties.

## Important MVP notes
- The three modes are a role selector for classroom simulation, not secure login or access control.
- Raw materials are tracked separately from finished menu stock. Recipe-based automatic ingredient deduction is not implemented yet because menu recipes and ingredient quantities must be defined.
- The sales total includes orders marked **Completed**. Queue actions are available in Admin in this MVP.
- Product codes are generated by category when the code field is left blank.
- For real deployment, add authentication, role permissions, database backups, audit logs, and transaction/refund handling.
